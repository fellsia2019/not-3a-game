# Visual Reference Index

Status: reference-only, outside `Assets/`. Эти файлы нельзя считать
runtime-ready или распространять без подтверждённых источников и лицензий.
Изображения остаются локальными и исключены из публичного Git-репозитория;
версионируется только этот индекс.

- `images.jpg` — основной style target: уютная pixel/near-pixel изометрия,
  модульные здания, ресурсы и крупные читаемые формы. Source/license: unknown.
- `df8f6479dd3d06067db27396997f2b892ae8979b-1679x724.png` — чистая сетка,
  контраст, ограниченная палитра и читаемая глубина. Source/license: unknown.
- `unnamed.webp` — reference для tower/enemy silhouettes и combat feedback;
  детализацию и branding не копировать. Source/license: unknown.
- `tower-defense-e1487170683784.jpg` — reference только для enemy route, HUD
  hierarchy и wave readability. Source/license: unknown.
- `images (1).jpg` — reference для лесного маршрута и размещения tower defense;
  визуальный стиль не является target. Source/license: unknown.
- `runefall-match3-meta-2D-village-park-garden-1024x576.avif` — reference для
  композиции поселения; слишком плотный/дорогой target для MVP.
  Source/license: unknown.
- `eMBQdE.jpg` — reference для крупных landmark и зонирования; не брать уровень
  уникального декора. Source/license: unknown.
- `images (2).jpg` — low-poly 3D alternative, отклонённая для MVP, чтобы не
  смешивать два asset pipeline. Source/license: unknown.

Перед использованием любого внешнего изображения добавить URL/автора/лицензию.
Оригинальные references, generated concepts и runtime assets хранить отдельно.
